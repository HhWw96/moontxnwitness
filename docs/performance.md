# v0.1.0 性能与验收记录

基线为公开 v0.0.6 的固定核心；同机、同工具链、同输入，完整 JSON 报告与完整 JSON 报告比较。原始记录见 [完整样本](../verification/releases/0.1.0/release-gate-v1.json)，固定输入见 `verification/fixtures/v006-comparison/`。

## 环境与方法

- win32 10.0.22000 / x64；AMD Ryzen 7 5800H with Radeon Graphics。
- Node v24.13.0；v0.10.14+7d59c7ec9；moon 0.1.20260920。
- 每场景预热 5 次、正式 30 次，3 批独立进程交替测量。中位数和 P95 是各批对应统计量的中位数；峰值 RSS 是独立进程峰值的中位数。
- 负载组以几何平均汇总；图内存比较使用同组场景的峰值 RSS 比率几何平均。冷模块加载、首次分析、分阶段数据与输出字节均包含在原始记录。
- 测量保留完整依赖与来源，不删传递边。摘要报告没有参与比较。正确性对照核对判断、依赖、最短证据及执行/版本约束；运行计数和图诊断字段不要求与旧算法相同。

## 重测与失败记录

`npm run benchmark` 先构建，缺少基线时自动下载公开 v0.0.6 portable 包，只取并核对固定 SHA-256 的核心；每次运行同时保留带时间戳的原始记录。`--quick` 和单负载组测量都不能代替完整验收。新环境需先安装文档列出的 MoonBit、Node、Python。

v0.0.7 建立基线；v0.0.8 图优化、v0.0.9 搜索、v0.0.10 缩减期间的失败及中间测量全部保留在各版目录。v0.0.11 没有改变分析算法，明确标注其测量为烟雾检查并引用 v0.0.10 的完整验收。

PostgreSQL 首轮 Linux 工作流在启动前因变量上下文配置失败；失败运行保留。修复后显式检出原始 v0.0.11 标签运行 20+20 轮，并分别记录源码提交与工作流提交；没有改写原标签或覆盖旧发布。v0.1.0 包含修复后的工作流，要求它在当前发布提交上实际通过。详见对应版本 publication.json。

测量是本机有限负载的结果，未来改动继续使用同输入、同输出范围与同样的正确性门槛。
