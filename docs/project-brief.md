# MoonTxnWitness 项目说明

**面向数据库与后端开发者的离线事务反例工具。** 读写日志常常能够显示异常现象，却难以说明哪些事务互相冲突、缺了什么观察、删除哪些噪声后仍能复现。MoonTxnWitness 连接采集、解释、缩减、复现和修复回归，分析在本地完成。

## 使用方式

下载 portable 包后，运行 `node dist/demo.mjs` 完成离线演示。真实 PostgreSQL 案例使用 `node dist/postgres-demo.mjs`，按说明安装可选驱动并配置测试数据库。每次运行保存新目录，缺少数据库时明确记录未执行。项目同时提供 Mooncakes 库、JS SDK 和命令行入口。

v0.1.1 的稳定采集入口使用可选 psycopg 3 适配器，支持同步及异步连接上的已有版本列点读写。应用通过连接入口和明确的 SQL 映射接入，由采集器记录实际观察，MoonBit 校验并生成可分析历史。它保留覆盖缺口，帮助使用者判断当前记录是否足够。

## 核心能力

- MoonBit 实现唯一版本点读写模型、WR/WW/RW/RT 依赖、强连通分量和全局最短环、有预算的串行补全、事务缩减、语义回放和中文报告。
- 边保留操作、版本和来源；搜索补全的版本顺序与原始采集事实分开。预算耗尽返回无法判定。
- v2 证据记录算法、模型、有效预算和版本来源；历史 v1 包保持原搜索顺序、预算和比较规则。
- PostgreSQL 两连接对照保留唯一版本读写、实际 SQL 结果、40001 回滚及全新事务重试。异常与修复案例支持缩减、导出和离线回放。

Node 提供本地文件操作和便携入口，Python 可选记录 SQLite/PostgreSQL 执行；事务分析算法继续由 MoonBit 实现。列表追加、受限关系集合、普通表来源及 ORM 诊断通过独立预览入口逐步扩展，具体范围见 [开发状态](development-status.md)。

## 验证与范围

验证包含独立串行重放、独立最短环核对、解析器差分、缩减复验、篡改检查、跨目标核心测试和真实数据库场景。逐版输入、环境、测试和性能结果保留在 [验证目录](../verification/)，性能按对应实现、负载及输出范围报告。

稳定寄存器入口分析带唯一版本的点读写及已声明约束。采集器依赖明确的 SQL 语义映射和受控写者范围；普通表、ORM 与范围事实使用各自的预览契约。任意 SQL 自动插桩和完整隔离模型分类继续扩展。项目检查提供的历史，不认证整个数据库的所有执行。

概念参考 Elle、Adya 的依赖模型和 PostgreSQL/SQLite 文档，代码及许可证见 [第三方说明](../THIRD_PARTY.md)。生产分析器不依赖 Elle；开发对照在独立环境调用固定上游检查器，并限定双方共同的原始事实范围。项目定位是 MoonBit 内可解释、可缩减、可复现的证据流程。

安装与运行见 [项目首页](../README.md)和[自动采集说明](automatic-capture.md)。后续按可用范围逐版发布，实际用户反馈和赛事审核分别记录。
