# 固定输入缓存

当前源码树保存正在维护的实现、测试程序和一个压缩输入索引。历史源码通过 Git 标签保留；旧证据回放与完整回归需要的原始文件，从公开发布附件按固定摘要恢复。v0.3.1 提供原始语料，v0.3.2／v0.3.3 提供小型兼容组件；多版本重放共享相同内容的文件，不复制历史源码树。

## 使用

直接运行 MoonBit 核心示例无需准备历史输入：

```sh
moon run --target wasm-gc src/demo
```

SDK 构建自动准备运行时；完整测试自动准备全部原始语料：

```sh
npm run build
npm test
```

Python 3.12 标准库即可运行恢复器，无需数据库驱动。首次恢复需要网络；可以提前准备，然后断网执行：

```sh
python scripts/input_cache.py prepare --scope tests
python scripts/input_cache.py prepare --scope tests --offline
```

设置 `MTW_INPUT_CACHE` 可让多个检出目录共用缓存。默认位置为当前目录的 `artifacts/input-cache`；缓存与项目位于同一文件系统时优先使用硬链接，避免重复占用空间。跨文件系统时使用独占创建的副本。缓存文件和恢复后的固定输入都应视为只读，修改会导致摘要检查失败。

## 绑定与失败行为

`scripts/frozen-inputs.json` 固定压缩索引、公开来源附件及其大小和 SHA-256；压缩索引逐文件固定目标路径、来源成员、大小、摘要和用途。下载不使用账户令牌。压缩索引、下载量、成员大小和展开总量均有上限。路径穿越、链接、重复 ZIP 成员、大小不符和摘要不符会中止，不会跳过测试。

缓存按内容摘要寻址；完整准备使用进程锁，最终文件以不覆盖已有内容的方式发布。磁盘满、损坏缓存、已有不同文件和同步失败均明确报错。只有完整的内容缓存已经存在时，离线恢复才无需原始 ZIP。成功返回包含已核验文件数、逻辑字节数和索引摘要。

标准 portable 包保留可运行的完整兼容闭包，离线执行旧胶囊无需另外下载；精简源码包首次构建 SDK 时恢复这些组件。完整测试的原始断言和输入不因源码精简而减少。缓存故障测试位于 `scripts/test_input_cache.py`。

这项改动减少当前源码归档和检出体积，没有重写 Git 历史。浅克隆使用 `git clone --depth 1`；需要旧版源码时再获取对应标签。
