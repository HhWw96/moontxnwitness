# 下载包内容

源码包保留构建源码、完整测试程序、冻结测试输入、许可、文档、案例，以及当前版本实际 PostgreSQL 复现包。便携包保留已经编译的运行核心、SDK/命令行、适配器、案例及相同的实际复现证据；运行需要 Node.js。

测试必须读取的历史材料也保留在包中，包括独立审计的固定 dislock/MLflow 输入、关系模型历史归档、ORM 原始轨迹和来源日志。精简打包只调整下载文件清单，不改变报告范围、异常证据、预算或分析结果，也不跳过现有消费者检查。

其余历史运行输出、失败记录和性能原始样本继续保留在 [GitHub 仓库](https://github.com/HhWw96/moontxnwitness) 的对应发布标签中；下载包不再重复携带全部历次输出。历史文档中的 verification 相对链接如未随包提供，请在对应标签下访问同一路径。

从源码运行测试仍需要 README 中列出的 MoonBit、Python 和可选协议测试驱动。便携包不包含 MoonBit 编译工具链，也不声称可以直接执行 npm test。历史基准比较或完整 Git 字节审计应使用完整 Git 检出；没有 .git 的源码下载不能执行 --git 审计。

后续版本只在其实际 PostgreSQL 复现执行完成后携带该版复现包，既有数据库记录保留原版本和来源信息。
