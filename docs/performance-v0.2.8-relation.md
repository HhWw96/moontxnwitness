# 关系缩减：固定负载性能记录

本记录比较公开 v0.2.7 基线 `c10b06c` 与关系缩减候选 `d7e170b`。该实现已用于 v0.2.8 集成；这次测量不是最终 v0.2.8 所有接口的整体性能成绩。寄存器和列表保留原实现。

| 指标 | 原实现 | 关系候选 |
| --- | ---: | ---: |
| 完整关系缩减中位数 | 8.6729 ms | 7.7138 ms |
| P95 | 13.8070 ms | 12.8805 ms |
| 中位数提速 | — | 1.1243× |
| 峰值 RSS 比 | — | 0.9798 |

三批中位数提速分别为 1.0912×、1.1295×、1.1060×。20 项原控制和 4 项额外列表 P95 控制通过；所有 1,484 份完整输出逐字节一致，24 份缩减结果在计时外完成最终验证。未达到 1.25× 优化目标，也没有达到明显的峰值内存下降目标。

协议保持四份冻结输入、七个场景，每批预热 5 次、正式 30 次、三批 AB/BA/AB 独立进程，共 56 个进程、1,260 个正式样本、210 次预热、14 次冷调用。冷调用包含进程、导入和输入开销，不宣称清空了操作系统文件缓存。RSS 包含预热及输出消费，单位和范围由原计划记录。
