## MoonTxnWitness v0.2.7

- 新增配置化 PostgreSQL 列表／关系来源采集，由 MoonBit 核验真实 SQL、结果交付与事务事实。
- 提供 SDK／CLI 分析、证据验证和完整来源包重放，保留无法判定与覆盖缺口。
- 采用 Unicode 流式 JSON 预检查，保留旧错误语义及公开 v0.2.6 的35家族兼容。

安装：`moon add HhWw96/moontxnwitness@0.2.7`，或下载便携包运行 `node examples/model-profile-roundtrip.mjs`。
