## 接下来完成的工作

定位性能尾部回退，取得独立 Linux/Native CI；为已有业务接入继续解决普通表版本来源。v0.1.2 的成本结果只覆盖版本来源 SQL 路径 B/A，不包含完整采集 C/A；单客户端测量也不代表并发锁等待、死锁和保留成本已验证。原型仍限制为固定键集合，拒绝未知键插入和主键变更。只有来源、负读、回滚、业务语义及开销验证通过后才进入稳定采集入口。

第二轮的 512 事务缩减中位数为基线 9.779 ms、当前 10.231 ms；P95 增加 3.148 ms，超过 2 ms 门槛。准备好输入的纯缩减阶段没有复现该回退，根因仍待确认；不能据此豁免失败。两轮记录分别保存在 `performance-v010-formal-2026-10-20T10-05-50-790Z.json` 与 `performance-v010-formal-2026-10-20T10-32-08-052Z.json`。普通表成本完整输入、原始延迟和结果保存在 `verification/provenance-prototypes/run-fff81b8ea9134993a1c3a2cebb8ebac5/`。

原始采集数据可能含业务数据，不能直接用于公开演示。当前公开测试数据均为受控合成数据；既有项目、真实问题、人工验收和赛事审核仍是独立待完成事项。
