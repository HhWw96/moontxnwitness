## 接下来完成的工作

已定位搜索的数字转换及字符串哈希热点，并实现完整缓存状态的紧凑编码；保留原来的向量信息、搜索顺序和预算。证据写入已修复，新搜索路径已按原协议测量；下一步冻结缩减的专用诊断并定位其尾部回退，有实质修复后才再次正式验收。为已有业务接入继续解决普通表版本来源和事务生命周期。v0.1.2 的成本结果只覆盖版本来源 SQL 路径 B/A，不包含完整采集 C/A；单客户端测量也不代表并发锁等待、死锁和保留成本已验证。原型仍限制为固定键集合，拒绝未知键插入和主键变更。只有来源、负读、回滚、业务语义及开销验证通过后才进入稳定采集入口。

本轮新增的普通表切片已经把服务器分配的实际版本身份交给原有 MoonBit 分析器，不需要手写操作历史。初始化在同一事务锁内安装、核验自有对象并读取初始快照；PostgreSQL 18 的 NOT NULL 目录差异导致的首轮失败保留。FK、规则和继承结构也加入稳定适配器的拒绝校验。详细边界、业务返回对照及运行方式见 [普通表采集实验](../experiments/provenance/CAPTURE_PROFILE.md)。这些受控场景不替代已有业务项目接入。

本轮先以带仪器的 18 个独立进程诊断输出开销，数据见 `analysis-diagnostics-2026-10-20T11-33-30-787Z.json`；再以 6 个独立进程诊断搜索缓存，数据见 `search-diagnostics-2026-10-20T12-32-32-516Z.json`。它们仅解释优化位置，不替代正式性能验收。先前冒烟完成 20 个完整负载和 15 个阶段，全部输出及 38 个保存快照经独立核对，仍明确 `smokeOnly=true`；后续正式轮次各自单列。

源码提交 `3d94d41920dd991bfa0a49fccb01b8076b371958` 的 [核心 CI](https://github.com/HhWw96/moontxnwitness/actions/runs/39425055711) 和 [PostgreSQL CI](https://github.com/HhWw96/moontxnwitness/actions/runs/39425055815) 均已通过。已实际下载三份 artifact、三份任务日志和固定提交源码，核对 GitHub 下载摘要、独立源码指纹、Linux Native 的 130 项测试、两平台消费者检查和真实数据库结果；详见 `verification/releases/0.1.1/independent-ci-3d94d41.json`。编译 core 字节没有上传到 CI artifact，收据中的 core 摘要属于 CI 运行时记录，不声称下载复算了编译二进制。原 121/127 项实现的收据保留。本页后续证据提交不改变该已测试实现的 MoonBit 源码指纹。
