# v0.2.6 model refutation implication repair

This development-only delta applies to `classification_models_v3.mbt` from commit `3a726fd59e8a61e4b07f419c5d698f4ec81f160f`. It changes model aggregation, not graph construction or any rule search.

A complete source-fact graph can prove a nonadjacent item anti-dependency cycle while a separate G2-item search exhausts its budget. Such a proof refutes PL2.99, PL3 and strict PL-SS. The model now records the actual proved source rule in `refutedBy`, plus a `refutationWitnesses` entry mapping a required rule to that source rule's original evidence. The original required-rule search remains unknown, with its unchanged counters, null evidence and `incompleteRules` entry. A model verdict does not imply all searches completed.

Each mapping includes `requiredRule`, `provedBy`, `specificAnomaly`, `impliedAnomalies`, `requiredRuleStatus`, `sourceRuleStatus` and `sourceEvidencePath`. The path references the full original witness already retained in `rules`; evidence is not duplicated or replaced. Only status `refuted` with nonnull evidence can supply a mapping. G0 remains the specific label when its proof also establishes G1c. The nonadjacent-to-G2-item implication is limited to the existing register/item and single-append list graph profiles. An RT-containing SSG cycle does not establish an ordinary G2-item cycle.

The existing required model rules, internal-validity applicability condition, graph search algorithms, budgets, counters and source observations remain unchanged. This is a pre-publication v0.2.6 correction under the existing candidate algorithm identity; source/runtime hashes distinguish this build. It does not alter any actual public v0.2.5 runtime or capsule. Future published-runtime compatibility remains a separate integration gate.

Development validation: strict JS check; original 51 classification tests unchanged plus 9 new regressions (60/60); one release JS build; original independent 4-case runner and 7-case negative runner reused byte-for-byte against the new runtime (11/11). A development-side field comparison confirms all original non-model result fields, every original rule status/counter/evidence, normalized source, dependencies, options and limits are unchanged across the four reports. The original source-fact oracle also passes. These are author checks, not independent acceptance, production adoption, actual database execution or performance measurements.

The initial independent 11-case failure and runtime remain immutable in their original evidence directory. The first new-test syntax failure (numeric literal method syntax), its source and raw compiler log are retained privately; only the syntax was corrected, without changing expectations. Private compiler logs/configuration may contain a local home path and are not in this source delta. A reviewer must independently rerun the unchanged original cases, verify each witness reference and source-fact cycle, and perform integration regressions before release.

Definition sources: [G-nonadjacent](https://jepsen.io/consistency/phenomena/g-nonadjacent), [G2-item](https://jepsen.io/consistency/phenomena/g2-item), [Serializable](https://jepsen.io/consistency/models/serializable).
