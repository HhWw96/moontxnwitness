# v0.2.1–v0.3.0 实施安排

以 cab3320 / v0.2.0 为起点，性能、采集和分类在隔离工作区并行开发，正式性能测量独占本机。实际状态记录在各版验收收据，计划本身不表示完成。

| 版本 | 声明目标 |
| --- | --- |
| 0.2.1 | v3 内部结构化规范化／分析，公开0.2.0同口径基线与实际兼容样本 |
| 0.2.2 | 指定 engine／连接工厂自动诊断插桩，真实结果交付及提交应答 |
| 0.2.3 | 有界事件及来源组同步、来源闭包窗口、完整A/B/C成本 |
| 0.2.4 | 固定base-user CRUD与已证明dislock profile自动投射与完整来源核验 |
| 0.2.5 | G0/G1c/G2-item类别专用搜索、独立分类证据及图内存 |
| 0.2.6 | 寄存器／列表六模型逐规则反证与蕴含闭包 |
| 0.2.7 | 列表／关系驱动自动事实映射、关系分类与缩减复用 |
| 0.2.8 | 冻结2000历史Elle共同范围对照、真实MLflow HTTP故障与修复回归 |
| 0.3.0 | 汇总实际已验证能力及推荐接口，不引入大型新功能 |

原观察、写效果、推断与执行信息分别保存。未知提交、来源缺失、不支持、计算及存储预算耗尽保持可见；六个模型名称不等于六种完整检查。精确搜索的既有12事务与新模型6事务／128操作上限保持，分类图容量另行约束。

每版只声明实际通过范围。性能候选未取得收益或控制组失败时保留首失败并回退，不降低证据、输出和耐久性保证换提速。公开说明聚焦新增、用法、兼容及实测；技术发布、用户反馈和官方审核分别记录。


当前 v0.2.1 范围收敛：稳定交付公开基线、完整输出复测工具和实际旧包回归。结构化候选两轮正式尾延迟控制未通过，已撤回默认路径；完整源码、运行包、657项候选测试与失败样本归档。此项优化继续顺延，不将候选提速记为稳定版成绩。v0.2.2/0.2.3 的自动采集和持久化实现独立验收后按顺序集成。


v0.2.2 集成状态：38项原始插桩单元测试、6项真实PostgreSQL18.6同步／异步及丢失提交响应测试通过；629项核心测试在JS、Wasm GC、Wasm分别通过，原生目标完成检查。14份公开20版及8份公开21版复现包通过兼容核验。独立复核、全新包和公开发布仍以本版最终收据为准。完整来源映射与采集成本没有提前记为完成。


v0.2.3 已发布：事件与可选来源的有界批量写入、水位、关闭及失败检查通过；公开下载与全新安装已核验。当前导出完整封存日志，任意来源闭包子窗口及正式 A/B/C 数字继续顺延。

v0.2.4 当前验证：新增固定 base-user 按 ID CRUD 的来源映射及独立 SDK/CLI，三个目标各672项核心、本轮两次原业务采集、原数据库回归与公开23版八份复现包已通过。全新包和公开发布以本版最终收据为准。dislock 未证明路径、任意 ORM 和自动列表/关系映射继续保留边界。图索引实验正在同源完整输出对照，尚未计入稳定性能收益。

## v0.2.6 后的执行状态

2026 年 10 月 24 日：v0.2.5、v0.2.6 已公开发布并核对下载。v0.2.5 提供 G0／G1c／G2-item 独立类别搜索和固定类别缩减；v0.2.6 增加寄存器与有界单追加列表的六模型逐规则检查、原始观察异常与专用非相邻反依赖搜索。旧版证据继续按原引擎重放，关系分类与模型保持缩减仍未支持。

v0.2.7 优先集成已经单独验证过的配置化列表／关系驱动投射，补齐当前主线接线、公开 v0.2.6 证据兼容和新消费者验证。已有候选的数据库结果只属于其原始源码，不替代集成版的真实数据库回归。v0.2.8 继续完成 Elle 共同范围实跑与 MLflow HTTP 故障修复前后对照；组件记录、单个 HTTP 种子与完整验收分别记录。

性能优化继续采用同输入和完整输出对比。[空实时边图复用](performance-experiment-empty-interval-reuse.md)未满足目标及控制组要求，已保留原始样本并撤回；新的 Unicode 流式 JSON 守卫已通过[完整调用性能对照](performance-experiment-streaming-json-guard.md)：固定 128 事务六模型 SDK 提速 1.23549 倍，控制组通过，峰值内存未下降。候选正在 v0.2.7 集成回归，尚未纳入已发布版本的默认实现。
