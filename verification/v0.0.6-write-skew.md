# MoonTxnWitness v0.0.6

发现确定的事务一致性异常
模型：serializable
事务：2；已提交：2；操作：4；依赖：2

## 异常环证据

1. T1 → T2 [rw，x]
   来源事务读到了较早版本，必须先于写入较晚版本的目标事务。
   操作下标 0 → 1，版本 x0 → x1
2. T2 → T1 [rw，y]
   来源事务读到了较早版本，必须先于写入较晚版本的目标事务。
   操作下标 0 → 1，版本 y0 → y1

证据包含构建图中事务数量最少的有向环；不声称整份历史已被全局最小化。

## 发现与缺失信息

- [violation] dependency_cycle: 这些事务的必要先后关系形成闭环，无法同时满足。；事务=T1, T2

## 版本来源

- x：已提交读 1，最终写 1，单写者推断，来源未确定读 0
- y：已提交读 1，最终写 1，单写者推断，来源未确定读 0
