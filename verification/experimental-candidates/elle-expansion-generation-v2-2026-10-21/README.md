# Frozen input authoring, before evaluation

This bundle contains the exact v2 preregistration and the independently accepted
small smoke prerequisite. Eleven bound input files total 153,243 bytes.
The original drafts and failed smoke attempts remain unchanged.

The manual `experimental-elle-expansion-generation.yml` workflow requires an
immutable 40-character `source_ref`. It checks the source bindings and invokes
the frozen generator once in isolated Python on a fresh Linux runner. No checker,
SDK, compiler, database or performance measurement runs. The workflow preserves
the first successful or partial output, its hashes, logs and failure receipts.

The independent smoke accepted six determinate agreements and retained two
empty-graph unknown differences. It does not certify this expansion, the newer
integrated source, all six models or a stable release.

The next gate is independent review of all 2,000 frozen histories, exact hashes,
first-occurrence alpha-program shape hashes, ten family quotas and shared-domain
facts. Shape uniqueness does not mean full graph-isomorphism uniqueness. Only
after that review may a separate batch evaluator be developed or run. All
unknowns, scope differences and failures must remain visible.
