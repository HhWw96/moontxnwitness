MoonTxnWitness 流式 JSON 守卫性能证据

本包保留一次正式实验的全部 60 个进程、1,800 个正式样本和 2,160 份完整原始报告（gzip），没有减少输出范围或重跑取优。

固定 128 事务完整六模型调用：中位数 1421.3299 → 1150.4180 ms，提速 1.23549 倍，达到本实验速度目标；P95 1776.9486 → 1259.4026 ms。
进程峰值 RSS 中位数 547284 → 560008 KiB，比值 1.02325，未达到内存下降目标。RSS 包含之前报告编码和归档分配，并非单次 SDK 专用峰值。
六个模型负载的几何平均提速 1.20184 倍、RSS 比值 0.99377，仅作描述，不能代表另一个整体性能目标通过。
9 个控制负载的 27 项分批与 9 项合并 P95 检查全部通过；完整输出仅允许实际 engine.coreSha256 字段差异，4 个分析控制组要求原文相同。

核验方式（只读取归档，不导入 SDK、不重新计时）：
python verify_evidence.py MoonTxnWitness-v0.2.6-streaming-guard-performance-evidence.tar.xz
也可解包到空目录后在包内运行 python verify_evidence.py。脚本只用 Python 标准库，不联网、不执行项目代码。结果统计使用偶数样本的上中位数和最近秩 P95。

包中附带原始 plan、protocol、10 份固定输入、5 个原始实验工具、94 个运行文件、产品补丁及8个新增测试、独立复核报告和可公开的正确性原件。逻辑路径均为包内相对路径；部分未改原文含 D 盘实验来源元数据，只用于溯源，不是核验依赖。

隐私与边界：
605 份正确性原件中，604 份原字节公开；1 份首次失败日志含本机 C 盘用户路径，仅公开其相对身份、字节数和 SHA256，原字节本地保留。没有修改或伪造原日志，详见 PRIVACY-SCOPE.json。因此本包支持独立只读核验全部测量结果，不能声称原 benchmark 的完整依赖可直接一键重跑；原始控制器仍要求被排除的日志。94 个运行文件已原字节提供。
