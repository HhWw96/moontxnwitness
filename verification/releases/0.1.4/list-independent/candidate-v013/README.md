# 先前 v0.1.3 列表 SDK 候选公开闭包

这批记录使用保留的 **v0.1.3** 分析/采集核心，验证新增固定列表 SDK 包装。它不是实际 v0.1.4 构建、数据库或发布验收。

`closure-manifest.json` 逐项绑定 194 份原字节复制文件，包括 48 份最终冻结输入及首版快照、独立首版解析异常、独立审计自身的字符串编码错误、最终 10 组/92 项通过记录、原作者 92 项记录和完整复跑所需文件。原始路径均为仓库相对路径；本次没有文件需要脱敏，也没有读取或复制凭据/私有目录。

`reproduction/repository/` 保留原运行布局。旧 SDK 和核心从实际冻结候选复制为对应 baseline，故不会错误使用作者后来构建的 v0.1.4 文件。输入、输出、旧核心均明确标记为先前版本。将该目录完整复制到一个新的短路径工作目录，在其根目录执行：

```text
node artifacts/v014-list-independent/check.mjs
```

需要已有 Node.js 和 Python 标准库，不安装依赖或访问数据库。Windows 应使用较短目录，避免嵌套示例超出系统路径长度。检查会生成自己的新 `artifacts` 输出；原件不覆盖。`fresh-replay-receipt.json` 记录上述公开镜像实际 10 组/92 项通过，`fresh-replay-child-receipt.json` 是原子收据字节。首个过深路径失败说明单独保留。

`original-evidence/` 按来源分别保存独立最终运行、首版 malformed 胶囊失败、测试自身编码错误及原作者最终运行。原收据中的旧 `artifacts` 引用是历史执行位置；对应公开副本由 manifest 的 `originalPath` 映射到本目录，并不要求消费者具有作者工作区。

更早 20,071 输入及旧 PostgreSQL 研究记录的摘要索引作为候选原件保留；它们不是这个小型复跑命令的输入，也不据此声称本轮重跑了全部历史研究。实际 v0.1.4 验收见父目录的新 `run14-*` 收据。
