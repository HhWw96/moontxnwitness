## 离线重放

本目录是完整轻量重放闭包，无源码镜像。需已有 Node 24；无需安装、Python、编译、数据库或网络。在本目录运行：

```powershell
node ./check.mjs --output-root ./replay-output
```

每次执行创建新的输出目录，不覆盖旧结果。`runtime/` 是本轮实际 v0.1.6，`prior-v015/` 是原 v0.1.5；`inputs/` 保留冻结期待、固定参考和旧胶囊，`example-repository/` 只含未改示例和必要执行文件。`preparation.json` 绑定源/runtime/input，`review-summary.json` 汇总已执行范围，`closure-manifest.json` 绑定整个目录的文件。原失败、许可证和历史版本来源一起保留。
